# PTI Messenger
PTI Messenger is a Windows-based internal messaging application developed during my Software Development Internship at the Press Trust of India (PTI), New Delhi.

## Technologies Used

- C++
- Electron
- JavaScript
- HTML
- CSS
- SQLite

## Features

- Real-time messaging
- File sharing
- User authentication
- Profile management
- Database integration
- Password and message encryption

## My Contributions

- Developed application components using C++, Electron, JavaScript, and SQLite.
- Worked on backend and UI development.
- Integrated SQLite for database management.
- Implemented messaging, file sharing, authentication, and profile features.
- Tested and debugged application functionality.

This repository contains project documentation only. The original application source code and internal PTI resources are not publicly distributed.
